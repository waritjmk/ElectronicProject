# EasyEngineer Code

โค้ดจากคลิปและโปรเจกต์ของ EasyEngineer ดาวน์โหลดฟรีที่ https://waritjmk.github.io/ElectronicProject/

## เพิ่มโปรเจกต์ใหม่
1. คัดลอกโฟลเดอร์ `projects/_template` แล้วตั้งชื่อใหม่เป็นตัวพิมพ์เล็กคั่นด้วยขีด เช่น `projects/01-led-button`
2. ใส่ไฟล์โค้ดลงในโฟลเดอร์นั้น แก้ `project.json` (ชื่อ คำอธิบาย แท็ก ลิงก์คลิป) และ `README.md`
3. รัน `node build.mjs` สคริปต์จะสร้างไฟล์ ZIP และหน้าเว็บใน `docs/`
4. commit แล้ว push หน้าเว็บจะอัปเดตเองใน 1–2 นาที

โฟลเดอร์ที่ชื่อขึ้นต้นด้วย `_` จะไม่ถูกแสดงบนเว็บ

## ก่อน push ทุกครั้ง
- ลบรหัส Wi-Fi, API key และ token ออกจากโค้ด (สคริปต์จะเตือนถ้าเจอรูปแบบที่น่าสงสัย แต่ตรวจเองด้วย)
- ไม่ใส่โค้ดหรือแบบที่เป็นของบริษัทอื่น
- ไฟล์ละไม่เกิน 100 MB
