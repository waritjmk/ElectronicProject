# วิธีใช้โฟลเดอร์ต้นแบบนี้

คัดลอกโฟลเดอร์นี้ ตั้งชื่อใหม่เป็นตัวพิมพ์เล็กคั่นด้วยขีด (เช่น `01-led-button`) แล้วใส่ไฟล์:

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `project.json` | ชื่อ คำอธิบาย หมวด แท็ก ลิงก์คลิป รายการอุปกรณ์ ตารางต่อขา ขั้นตอน |
| `cover.jpg` | รูปปกโปรเจกต์ (แนวนอน 16:9) |
| `wiring.png` | รูปผังการต่อวงจร |
| `main.ino` (หรือไฟล์โค้ดอื่น) | โค้ดหลัก ชื่อไฟล์ต้องตรงกับ `code.main` |

ช่องใน `project.json`:
- `category` คือหมวดที่ใช้จัดกลุ่มในหน้ารวม เช่น Arduino, ESP32, หุ่นยนต์
- `youtube` ใส่ลิงก์คลิปหรือ ID ก็ได้, `tiktok` ใส่ลิงก์คลิป เว้นว่างได้ถ้าไม่มี
- `parts` แต่ละชิ้นมี `name`, `qty`, `note`, `link` (ลิงก์ซื้อ เว้นว่างได้)
- `wiring.pins` เป็นคู่ `["จาก", "ต่อไปที่"]`
- ช่องไหนไม่มีข้อมูล ลบออกหรือเว้นว่างได้ ส่วนนั้นจะไม่แสดงบนหน้าเว็บ

> อย่าใส่รหัส Wi-Fi, API key หรือ token จริงลงในโค้ด ใช้ `YOUR_WIFI_NAME` / `YOUR_PASSWORD` แทน
