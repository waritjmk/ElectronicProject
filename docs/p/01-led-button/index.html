โปรเจกต์ทั้งหมด / Arduino

กดปุ่มแล้วไฟติด

โปรเจกต์แรกสำหรับมือใหม่ ต่อปุ่มกดกับหลอด LED เข้ากับ Arduino แล้วเขียนโค้ดบรรทัดเดียวให้ไฟติดตามปุ่ม

  • Arduino UNO
  • มือใหม่
ดาวน์โหลดโค้ด (ZIP) 3 KBดูรายละเอียด

หน้าตัวอย่าง โปรเจกต์นี้ทำขึ้นเพื่อทดลองหน้าเว็บ โค้ดเขียนตามวิธีมาตรฐานแต่ยังไม่ได้ทดสอบบนบอร์ดจริง และคลิปที่แสดงอาจไม่ตรงกับโปรเจกต์

02อุปกรณ์ที่ใช้

ตัวต้านทาน 10kΩ1ดึงขาปุ่มลงกราวด์ (pull-down)

โพรโทบอร์ดและสายจัมเปอร์1 ชุด

03การต่อวงจร

จากต่อไปที่
5Vขาปุ่มด้านที่ 1
ขาปุ่มด้านที่ 2ขา 2 ของ Arduino และตัวต้านทาน 10kΩ
ตัวต้านทาน 10kΩ อีกด้านGND
ขา 13ตัวต้านทาน 220Ω แล้วต่อเข้าขายาว (+) ของ LED
ขาสั้น (-) ของ LEDGND

ตัวต้านทาน 10kΩ ทำให้ขา 2 อ่านค่าเป็น LOW แน่นอนตอนไม่ได้กดปุ่ม ถ้าไม่ใส่ ไฟจะติดๆ ดับๆ เอง

04Source code

ดาวน์โหลดโค้ด (ZIP) 3 KBดูทุกไฟล์บน GitHub (เปิดแท็บใหม่)
led_button.ino
// กดปุ่มแล้วไฟติด
// ปุ่มต่อที่ขา 2 (มีตัวต้านทาน 10k ดึงลง GND) หลอด LED ต่อที่ขา 13 ผ่านตัวต้านทาน 220 โอห์ม

const int LED = 13;  // ขาที่ต่อหลอด LED
const int BTN = 2;   // ขาที่ต่อปุ่มกด

void setup() {
  pinMode(LED, OUTPUT);  // ขา LED เป็นขาส่งไฟออก
  pinMode(BTN, INPUT);   // ขาปุ่มเป็นขาอ่านค่า
}

void loop() {
  // อ่านค่าจากปุ่ม แล้วส่งค่าเดียวกันไปที่ LED
  // กดปุ่ม = HIGH = ไฟติด, ปล่อยปุ่ม = LOW = ไฟดับ
  digitalWrite(LED, digitalRead(BTN));
}

05ขั้นตอน

  1. ต่อวงจรตามผังโดยยังไม่เสียบสาย USB
  2. เปิดไฟล์ led_button.ino ด้วย Arduino IDE
  3. เลือกบอร์ด Arduino UNO และพอร์ตที่ถูกต้อง แล้วกด Upload
  4. กดปุ่มค้างไว้ ไฟ LED จะติด ปล่อยแล้วดับ
